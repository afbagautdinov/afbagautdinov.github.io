# Ophir Labs

Сайт разработчика для карточек приложений в магазинах — https://afbagautdinov.github.io/.
GitHub Pages публикует содержимое папки `docs` ветки `main`. Файлы в этой папке становятся общедоступными.

## Как разместить app-ads.txt

1. В РСЯ откройте «Настройки → Общие → app-ads.txt» и скачайте файл вашего издательского аккаунта.
2. [Откройте загрузку в папку docs](https://github.com/afbagautdinov/afbagautdinov.github.io/upload/main/docs), выберите `app-ads.txt` и сохраните изменение в `main`.
3. После публикации откройте https://afbagautdinov.github.io/app-ads.txt без входа в GitHub. Сверьте строки с файлом РСЯ.
4. В описании каждого приложения в RuStore укажите сайт разработчика https://afbagautdinov.github.io/. В кабинете РСЯ отправьте файл на проверку.

Для всех приложений с этим сайтом используется один файл `docs/app-ads.txt`. Если они подключены к одному издательскому аккаунту РСЯ, достаточно загрузить его один раз. При добавлении другой сети объедините разрешённые строки с существующими, сохранив записи для остальных приложений. Репозитории с исходниками приложений можно держать приватными.

[Документация РСЯ](https://ads.yandex.com/helpcenter/ru/support/faq/app-ads-txt)
