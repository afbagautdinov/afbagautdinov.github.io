# Ophir Labs

Исходники сайта разработчика Ophir Labs. После включения GitHub Pages стандартный адрес проекта будет https://afbagautdinov.github.io/ophirlabs.github.io/.
Для публикации в GitHub Pages выберите содержимое папки `docs` ветки `main`. Файлы в этой папке становятся общедоступными.

## Как разместить app-ads.txt

1. В РСЯ откройте «Настройки → Общие → app-ads.txt» и скачайте файл вашего издательского аккаунта.
2. [Откройте загрузку в папку docs](https://github.com/afbagautdinov/ophirlabs.github.io/upload/main/docs), выберите `app-ads.txt` и сохраните изменение в `main`.
3. Для РСЯ файл должен открываться по пути `/app-ads.txt` от корня домена. Стандартный адрес этого проекта включает вложенный путь. Для публикации из этого репозитория в корне можно подключить собственный домен.
4. После настройки домена проверьте файл без входа в GitHub и укажите адрес сайта разработчика в описании каждого приложения в RuStore. В кабинете РСЯ отправьте файл на проверку.

Для всех приложений с этим сайтом используется один файл `docs/app-ads.txt`. Если они подключены к одному издательскому аккаунту РСЯ, достаточно загрузить его один раз. При добавлении другой сети объедините разрешённые строки с существующими, сохранив записи для остальных приложений. Репозитории с исходниками приложений можно держать приватными.

[Документация РСЯ](https://ads.yandex.com/helpcenter/ru/support/faq/app-ads-txt)
